THE CORE IDEA

How BloomCheck decides

01

Hash the address

SHA-256 digests are used with double hashing to calculate seven repeatable bit positions.

02

Read the bits

If any checked bit is 0, this filter rules the address out. If every bit is 1, the address is only a possible match.

03

Verify exactly

Possible matches are checked against SQLite. This distinguishes a real member from a false positive.
